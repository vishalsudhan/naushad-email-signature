How to install

Gmail

  1. Click Copy for Gmail.
  2. Gmail → Settings → See all settings → General → Signature → Create new.
  3. Paste, then Save Changes. Don't resize the images.

New Outlook / Outlook on the web

  1. Click Copy for Outlook.
  2. Settings → Accounts → Signatures → New signature.
  3. Paste, name it, save and set as default.

Classic Outlook (Windows)

  1. Click Download .htm.
  2. Press Win+R, open %APPDATA%\Microsoft\Signatures.
  3. Move the file there, then File → Options → Mail → Signatures and select it.
After pasting, the name, title, phone, website and address can be edited directly in Gmail or Outlook. Images are hosted at https://naushad-email-signature.vercel.app/assets/. Keep this site online so they keep loading.
